## Project Description
Process for new customers: From first inquiry to completed setup. Includes questionnaire, knowledge base creation, and handover.

## Workflow
1. Customer fills out onboarding questionnaire
2. Answers are converted into Knowledge Base
3. Knowledge Base is deployed to server
4. Customer receives access credentials
